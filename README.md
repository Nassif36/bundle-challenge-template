1. Open Preview

Open the store preview to begin testing the T-Shirt product flow.

Go to any T-Shirt product page to start testing variants and discounts.

3. Test Size and Color Combinations

Select different size and color combinations.

Ensure the sold out status updates correctly.

Verify that your selection is saved when switching between options.

4. Add to Cart

Click Add to Cart.

On the cart page, ensure the correct variants for color and size are added, matching your selection.

5. Navigate to Checkout

Proceed to the checkout page to verify pricing and discounts.

6. Check Discounts

Confirm that the Orange T-Shirt and T-Shirt Bundle products have the correct discount applied.

6.1 Add a Gift Box Product

Add a Gift Box product to the cart.

Notice that it does not receive a discount since it has no bundle product metafield set.
